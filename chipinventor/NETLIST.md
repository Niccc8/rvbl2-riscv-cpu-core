# Wiring checklist - Stage 3

GENERATED by `scripts/gen_docs.py` from `ci_top.v` and `blocks/*.v` - do not hand-edit.

Two canvas projects. `rvbl2_soc` is the core, data memory and peripherals, built on a **copy** of the graded Phase 2 project and then placed as IP inside `top`, the chip. `scripts/check_export.py` audits the export of `top` against this document's source, wire by wire.


## Before you start

- **Copy the graded Phase 2 project first** and make every change on the copy. The platform keeps no version history.
- Name the SoC project exactly **`rvbl2_soc`**: the export names its module after the project, and both the checker and the FPGA wrapper expect that name.
- The canvas **cannot slice a bus** and **cannot draw a constant**. That is why `address_decoder` has `periph_chain_o` (a constant zero to start the read-back chain) and why `gpio_bits` exists.
- **Inout Pins: C is the data, D is the enable.** The platform writes `assign pin = D ? C : 1'bZ;`. Wire `gpio_bits.cN_o` to **C**, `gpio_bits.dN_o` to **D**, and the pin's right-hand terminal to `gpio_bits.pN_i`. A swap still compiles, so the checker tests it explicitly.
- `lsu`'s port names still read backwards: `mem_data_o` is an input, `core_data_i` an output.
- `rx_i` must idle high on the real chip; the testbench holds it high.
