# Block form fields

GENERATED by `scripts/gen_docs.py` from `blocks/*.v` - do not hand-edit.

One section per block, giving exactly what goes in each field of ChipInventor's Add Block
dialog. Paste the matching file from `blocks/` into the Code field; nothing in those files
needs editing or trimming first. Blocks marked **new** or **changed** are the Stage 3 work;
every other block is exactly as in the Phase 2 project.

Author and Icon are yours to set. Leave Validate, Block Width, Block Technology and the
two HDL-Specific fields empty unless the platform asks for them.
